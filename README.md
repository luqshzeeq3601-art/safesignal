# SafeSignal — Lone Worker Emergency Beacon

An Android app that detects a fall or an unresponsive worker, counts down so a false alarm can be cancelled, then sends an alert with location and battery level to a dispatcher console and waits for an acknowledgement.

**Status:** M0 (scaffold) complete. See `docs/agile/backlog.md` for the milestone list.

## Requirements

- JDK 17
- Windows 11 with PowerShell 7 (scripts also run on Linux with `pwsh`)
- Android SDK — installed by `scripts/setup-sdk.ps1` at M5

## Build

```powershell
.\gradlew.bat projects   # lists the modules
.\gradlew.bat check      # all tests
```

## Honest limits

- Fall traces are synthetic, generated by a script.
- The server has no authentication (localhost demo).
- Emulator battery figures are model estimates, not measurements.
